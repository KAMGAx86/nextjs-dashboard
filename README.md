# 📊 Next.js Dashboard

> Projet réalisé en suivant le tutoriel officiel de Next.js.

---

## 📌 Description

Next.js Dashboard est un projet réalisé dans le cadre du tutoriel officiel de Next.js.

L’objectif était de comprendre en profondeur :

- L’architecture App Router
- Le rendu côté serveur (Server Components)
- Le routing dynamique
- La gestion des données
- Les bonnes pratiques modernes avec Next.js

Ce projet m’a permis de consolider mes bases en développement full-stack avec Next.js.

---

## 🛠️ Technologies utilisées

- **Next.js**
- **React**
- **TypeScript**
- **App Router**
- **Server Components**
- **Tailwind CSS**
- Base de données PostGresSql

---

## 🎯 Objectifs pédagogiques

- Comprendre la structure moderne d’un projet Next.js
- Implémenter un dashboard dynamique
- Gérer les routes et les layouts
- Manipuler des données côté serveur
- Mettre en place une authentification basique (si incluse)
